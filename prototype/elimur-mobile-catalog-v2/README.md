# elimur — каталог интимных товаров (18+)

Мобильный и десктопный веб-каталог. Тёмная бордовая тема, золотые и оранжево-красные акценты, декоративные тропические листья. Российская аудитория, оформление заказа через Telegram.

## Файлы

| Файл | Что это |
|---|---|
| `Elimur.dc.html` | Мобильная версия (375px), интерактивный прототип |
| `Elimur Desktop.dc.html` | Десктопная версия (контейнер 1280px) |
| `Elimur (все версии).dc.html` | Обёртка с переключателем моб./десктоп |
| `Elimur-полный.html` | Всё в одном офлайн-файле (для загрузки в Claude) |
| `Elimur-Desktop-standalone.html` | Только десктоп, один офлайн-файл |
| `image-slot.js`, `support.js` | Рантайм (нужны рядом с `.dc.html`) |

**Как открыть:** двойной клик по `Elimur-полный.html` — работает офлайн. Или откройте любой `.dc.html` (рядом должны лежать `support.js` и `image-slot.js`).

**Фото товаров:** плейсхолдеры принимают перетаскивание — перетащите свои снимки (например, с карточек Wildberries) прямо на них, сохранятся между перезагрузками.

## Разделы

Возрастной гейт 18+ · Главная/Каталог (10 товаров, фильтры, полоса доверия, промо-баннер WB) · Карточка товара · О бренде (+ юр. реквизиты) · Отзывы · Гайды · Помощь/FAQ/Доставка/Контакты · Дизайн-спека для разработчика.
